# Hunter Codex - WoW Forever hunter simulations

Static comparison of hunter specs, talents and gear for World of Warcraft: Forever, simulated with
[wowsims/forever](https://github.com/wowsims/forever) (MIT). Every build links to the exact setup in the
[WoWSims Forever hunter sim](https://www.wowsims.com/forever/hunter/dps/).

Pre-release model output, not in-game measurements: see the Caveats tab. Fan-made, not affiliated with Blizzard Entertainment.
Item and talent tooltips/icons by [Wowhead](https://www.wowhead.com/forever).
